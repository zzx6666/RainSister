# 项目原创 BGM 说明

本目录中的 7 条背景音乐均为《RainSister》项目的原创程序化配乐。它们不是《新世纪福音战士》官方音乐，也不是对任何既有 OST、原声、歌曲、音效库或第三方采样的改编、拼接或克隆。

## 生成方式

- 生成器：`generate-bgm.mjs`，配合 `synth-engine.mjs` 与 `track-recipes.mjs`。
- 合成：本地振荡器、确定性伪随机噪声、ADSR 包络、滤波近似、多抽头延迟与等功率循环交叉淡化。
- 采样率：22050 Hz。
- 位深：16-bit PCM。
- 声道：单声道。
- 循环：每章 14–16 秒，0.18 秒等功率首尾交叉淡化。
- 随机性：固定种子，同一 Node.js 环境下重复生成应得到相同 WAV 与 SHA-256 摘要。
- 外部音源：无。生成过程不发起网络请求，不读取其他音频文件。

## 使用与权限

这些 WAV 是项目内生成的原创程序化音频，仅计划用于本项目的个人、非商业同人演示，不包含第三方录音或个人声音。音频本身的生成不改变《新世纪福音战士》相关名称、角色、影像和商标的权利归属。

公开传播、商业使用、再分发或单独将音频作为素材库发布前，仍需重新评估项目整体授权与平台政策。本说明不构成对 EVA 官方素材、角色或商标的授权。

## 复现与校验

```powershell
node .\assets\audio\bgm\generate-bgm.mjs
node .\assets\audio\bgm\generate-bgm.mjs --check
```

生成器会校验 RIFF 长度、WAVE/PCM 格式、`data` 区块、采样率、声道、位深、峰响度、RMS、首尾能量差、循环接缝，以及 7 条音轨总计不超过 6 MiB 的媒体预算。
