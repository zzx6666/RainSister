# NERV 同步协议 / 动态视觉分镜

> 文档状态：Three.js + GSAP 实现前视觉稿  
> 基准日期：2026-10-19

> 依据范围：仅通读 `PRODUCT.md`、`DESIGN.md`、`index.html` 与 `assets/` 现有文件；未读取或修改 `styles.css`、`script.js` 等实现文件。  
> 用途：指导“电影式混合 3D”重构，不把最终体验降级成静态角色卡片。

## 0. 导演命题

### 0.1 一句话空间故事

观众进入一套仍在运转的 NERV 同步训练装置：红色 AT 力场先封闭视野，再被“同步”指令切开；镜头穿过巨幅日文标题和真实影像，依次经历角色翻转、机体扫描、使徒力场变形与城市上升，最后在心之壁重新聚合时完成崩解。

### 0.2 核心视觉原则

1. **真实画面上空间，虚构几何做空间。** 角色、机体、使徒、海报和短片只作为有来源的真实影像纹理；建筑、机库、石板、力场、粒子和光属于程序化空间设计。不得用写实 3D 重建角色、EVA 或使徒，也不得 AI 生成“官方画面”。
2. **一个镜头语言贯穿首尾。** 首屏的八边形 AT 力场、终幕的八边形聚合、点击中和后的碎裂共用同一份着色器状态和棱片拓扑，形成闭环。
3. **不是通用霓虹 HUD。** 90 年代动画海报、赛璐璐颗粒、纸张、黑场、硬切、遮片和局部色差是主动语言。禁用全屏泛光、蓝紫渐变仪表盘、无意义数据雨和每段相同的淡入上浮。
4. **DOM 负责真相，WebGL 负责空间。** 标题、人物介绍、台词、按钮、来源与授权说明必须在普通 DOM 中保持可选择、可聚焦、可朗读。Canvas 整体 `aria-hidden="true"`，不得把正文画进纹理或 WebGL 文字。
5. **两种阵营语法。** NERV 使用纸白、近黑、警告红、应急橙与少量酸绿；运动以机械光圈、直线位移、扫描门和同步刻度为主。SEELE 使用近黑、信号红、骨白、黑石碑与硬切；运动以横向错位、多面体变形、遮片和短促色差为主。酸绿只表示“同步/可用”状态，紫与蓝只服务 EVA-01 的身份时刻。

### 0.3 必须成立的六类空间行为

| 行为 | 场景 | 用户感知 |
|---|---|---|
| 力场光圈破门 | `#top` | 从封闭到被允许进入 |
| 双面影像翻转 | `#children` | 1995 与 2021 是两套记录，不是同一张卡换色 |
| 机库深度扫描 | `#evangelion` | 镜头绕真实机体影像移动并揭示缺陷和驾驶员 |
| AT 力场弯曲与碎裂 | `#angels` | 力场是用户能中和的空间对象 |
| 地下城市上升 | `#tokyo-3` | 镜头从 Geofront 穿出，城市结构逐层升起 |
| 胶片走廊与终幕崩解 | `#records`、`#release` | 时代被推进，最后全部被吸入同一心之壁 |

## 1. 镜头与坐标约定

### 1.1 画幅与安全区

- 主关键帧：1920 × 1080，16:9。
- 桌面验收：1920 × 1080、1440 × 900；移动端：390 × 844。
- 3D 标题安全区：画面中心 80% 范围。DOM 阅读区：桌面左栏宽 34–40vw，右场留给空间与人物；移动端固定为下方约 42vh 的可读层，重要正文不少于 16px。
- 人物面部、机体编号、海报标题和授权署名不得被字幕条、进度条或 WebGL 粒子遮挡。
- 功能标签最小 12px；法律来源文字最小 11px；正文最小 16px，移动端点按区域最小 44 × 44px。

### 1.2 进度与坐标系

- 全局滚动进度记作 `p ∈ [0, 1]`；每个场景另设本地进度 `s ∈ [0, 1]`。
- Three.js 世界使用右手坐标：镜头默认朝 `-Z` 看，`+Y` 向上。文中 `C` 为相机位置，`T` 为注视点，`FOV` 为垂直视场角。坐标是视觉基准，不是最终硬编码值。
- 全站只创建一个 `WebGLRenderer`。每个场景通过统一接口接收 `p`、`s`、指针和音频电平。
- `ScrollTrigger` 只映射滚动到镜头与状态，不劫持滚轮，不改写浏览器原生滚动速度。
- 推荐总固定滚动预算为 2000–2300vh；移动端压缩到桌面的 60–70%。首次进入时由“开始同步”执行一次 1.4–1.8 秒的导演动画，之后仍由用户自由滚动。

### 1.3 景深策略

- 高画质：使用轻量 `BokehPass` 或自定义窄半径景深，最大模糊保持克制；只对当前场景启用。
- 中画质：关闭真实景深，以远景降对比、缩放和遮罩模拟层次。
- 移动/低画质：取消后处理模糊，仅保留清晰前后景和局部雾化纹理。
- 焦点在每个关键镜头上明确：人物卡焦点在眼睛，机体焦点在缺陷部位，使徒焦点在核心/面具，城市焦点在上升的装甲层，终幕焦点在八边形中心。

### 1.4 硬切与安全闪烁

- 允许硬切的位置：`p=0.10`、`0.32`、`0.47`、`0.66`、`0.78`、`0.90`。
- 硬切使用 1–2 帧近黑过渡，不做全屏白闪。红色闪烁频率不得超过 3Hz，不制造高频频闪。
- 遮片优先使用竖向百叶、八边形光圈、扫描门、横向错位和几何 wipe；淡入只用于数据层可读性，不承担空间转场。

## 2. 五张 16:9 关键帧

### K01 / INITIALIZE：启动 / 首屏与 AT 力场

**镜头功能**：先让观众看到自己“被拒绝接入”，再用按钮或键盘主动打开力场。标题必须在力场闭合时已经可读，不能等待 3D 加载后才出现。

**构图**

- 画面中心是一枚接近满幅的红色八边形 AT 力场，外圈有极细同步刻度和缓慢收缩的同心线。
- 中央日文大字 `同期` 竖排或偏轴排列，压住力场中轴；DOM 主标题 `同步协议` 与副标题 `SOLITUDE / SYNCHRONIZATION PROTOCOL` 位于左侧安全区。
- 两个入口按钮置于左下或底部：`开始同步`（主操作）与 `静音浏览`（次操作）。两者都是真实按钮，不是装饰性 HUD。
- 初始画面保留 35–45% 黑场，不填满粒子；红色只在力场棱线和状态灯上出现。

**前 / 中 / 远景**

- 近景：DOM 标题、同步率读数和按钮；少量红色粉尘在镜头前低速漂移。
- 中景：程序化八边形力场，八块三角棱片带轻微厚度；边框由 `LineSegments` 或窄面几何构成。
- 远景：近乎全黑的 NERV 同步腔体，只有两三条极暗结构线提示纵深。力场后方预埋真实主视觉层，但初始被遮住。

**真实影像层**

- 首帧不依赖真实影像，避免在加载期间露出空白海报。
- 破门后把 `assets/characters/group.png` 放入后方第一层群像，作为当前可用的同人主视觉并保留来源标签。
- 若后续取得可核验的官方主视觉，只替换纹理和 `MediaCredit`，不改镜头结构。不得把现有同人图标成官方。

**字体尺度**

| 元素 | 1920 × 1080 | 390 × 844 |
|---|---:|---:|
| `同期` 日文巨字 | 260–340px / 14–18vw | 96–120px |
| DOM 主标题 | 64–88px | 38–48px |
| 英文技术副题 | 15–18px | 12px |
| 引导正文 | 18–22px | 16px |
| 按钮标签 | 14–16px | 14px |

**色彩**：近黑 `#080807`、暖白 `#f4f1e7`、警告红 `#c62118`、应急橙 `#e96b22`。酸绿只用于可用按钮和同步成功状态。

**主交互**

- 点击 `开始同步`：用户手势解锁声音权限；力场在 1.4–1.8 秒内从八块棱片向四周收束，镜头穿过中心。
- 点击 `静音浏览`：同样打开力场，但不请求声音；按钮状态必须持久可辨认。
- `Enter` / `Space` 在按钮聚焦时执行同一动作；不得用全屏点击区抢占焦点。
- 指针只产生 ≤2° 的镜头偏转和极轻的棱线弯曲，鼠标离开后 300ms 内回正。

**移动端翻译**

- 力场占画面上方 54vh，DOM 标题与两个按钮固定在下方，以单列排布。
- 关闭近景粉尘和真实景深；力场棱片从 16 段降到 8 段。
- 破门改为 180ms 几何遮片加一次硬切，不使用穿屏长镜头。

**Three.js / GSAP 钩子**

- `C(0, 0, 8)` → `C(0, 0, 3.6)`，`T(0, 0, 0)`，`FOV 38→54`。
- 力场平面预置在 `z≈4`；标题片中轴 `z≈2.7`；真实影像层从 `z≈0` 向 `-6` 展开。
- GSAP：`field.uniforms.open` 从 `0→1`，八棱片 `rotationZ` 每片差 45°，`camera.position.z` 使用 `power3.inOut`；DOM 按钮反馈在 120ms 内完成。

### K02 / CHILDREN：1995 / 2021 角色空间

**镜头功能**：把五个驾驶员的角色识别与时代差异做成一次真实的空间翻面，同时保持介绍可读。不是卡片列表逐张淡入。

**构图**

- 桌面左 38vw 是 DOM 角色正文，右场是一条向深处延伸的立体档案廊。
- 碇真嗣位于中轴最近层；绫波丽在其右后方；明日香在左后方形成对抗；渚薰与真理位于更远两层，形成“终点”和“新记录”的不对称关系。
- 美里、律子、源堂的 NERV COMMAND 副档案安置在走廊下沿，以较浅的 3D 层和较小信息板出现，避免与前五位驾驶员抢主次。
- 每个角色牌都有正面 `角色识别层` 与背面 `年代档案层`；翻面必须从侧面看到厚度与遮片，不得整卡瞬间换图。

**前 / 中 / 远景**

- 近景：DOM 标题、当前角色正文、初登场、身份、独处记录与日语播放按钮。
- 中景：5 块双面立体影像；每块影像至少拆成人物、前遮片、背景、扫描线四层。
- 远景：纸白档案室/连续白色遮片，远处有极淡的 MAGI 网格和同步率刻度。纸张纤维作为低频纹理，不做数字噪点墙。

**真实影像层**

- 当前可用：`shinji.webp`、`rei.png`、`asuka.webp`、`misato.webp`、`ritsuko.jpg`、`gendo.gif`、`kaworu.webp`。
- 双面影像最终应使用可核验的 1995 TV 与 2021 新剧场版画面；在素材年份未核验前，只能作为“角色识别层”，不得直接标成 1995/2021 官方剧照。
- 惣流·明日香·兰格雷与式波·明日香·兰格雷必须分别标注年代和姓名，翻面是“换记录”，不是暗示完全相同的人物档案。
- 真理在旧作面显示正式空档案：`NO RECORD / 1995—1997 記録なし`，不得拿其他角色图填充。
- 美里、律子和源堂素材分辨率较低，显示尺寸必须小于主要驾驶员；源堂在 `#angels` 只保留 SEELE 关系回链，不重复创建第二个完整档案 ID。

**字体尺度**

| 元素 | 1920 × 1080 | 390 × 844 |
|---|---:|---:|
| 场景章节号 `01` | 180–240px | 72–88px |
| 场景标题 `适格者` | 88–120px | 42–54px |
| 当前角色中文名 | 52–68px | 30–36px |
| 日文姓名 | 24–30px | 17–20px |
| 正文 | 18–21px | 16px |
| 年份/状态标签 | 12–14px | 12px |

**色彩**：暖纸白、墨黑、MAGI 橙、酸绿同步状态；EVA-01 蓝与紫只作为真嗣角色层的局部识别色。不得把整个场景染成紫绿霓虹。

**主交互**

- 默认跟随滚动选择当前角色；点击立绘或键盘 `←/→` 切换角色。
- 点击 `1995 / 2021` 切换面，卡片先绕 Y 轴转 90°，在不可见侧面完成纹理替换，再转回；中低画质以 110ms 遮片代替连续旋转。
- 指针产生 ≤6° 视差；角色本人脸部不做夸张位移。
- 音频按钮单独控制，页面不同时播放两条日语语音。

**移动端翻译**

- 取消横向 3D 走廊，改成一张主角色影像 + 下方年代分段按钮；切换使用纸张遮片和 120ms 位移。
- 美里、律子、源堂作为横向可滑副档案，必须有明确标题与页码，不依赖手势发现。
- `NO RECORD` 面板保留空白和说明，不为了视觉完整而伪造照片。

**Three.js / GSAP 钩子**

- 五张主卡分布在 `z=-2, -5.5, -8.5, -12, -15`，`x` 采用 `+2.4, -2.2, +1.4, -1.1, +2.8` 的不对称节奏。
- 相机 `C(0, 0.4, 9)` → `C(0.8, 0.2, -1)`，并围绕当前角色轻微横移；`FOV 46→42`。
- 卡面翻转用 `rotationY: 0→π`，在 `π/2` 时调用 `swapTexture`；背面不可镜像文字，文字应放在 DOM 或不随卡片翻转的正面标牌中。

### K03 / EVANGELION：EVA 机库与深度扫描

**镜头功能**：让机体不是一张横向大图，而是被机库结构、扫描光和驾驶员数据包围的空间对象。观众应能看到“缺陷部位被检查”，而不是看一张带网格的海报。

**构图**

- 一线巨大的 EVA 机体影像从左下向右上伸出，占画面 65–75%；镜头贴近肩部和胸部，编号 `01` 以冷白描边数字压在右侧黑场。
- 左侧是机库编号与机体选择器 `00 / 01 / 02 / 08`；下方为当前驾驶员、同步率、机体状态与来源。
- 机库框架形成纵深笼子，扫描平面从机体前方向后推进，经过面部时焦点短暂落在眼睛，经过胸部时落在缺陷与插入栓接口。

**前 / 中 / 远景**

- 近景：电缆、警示栏、扫描环、DOM 选择器与编号。
- 中景：真实机体影像的多层深度卡、半透明舱门和扫描平面。
- 远景：程序化 NERV 机库梁架、升降平台、应急橙灯与深黑通道。

**真实影像层**

- 计划材质：EVA-00、EVA-01、EVA-02、EVA-08 的官方或可核验动画画面。
- 当前素材目录没有 EVA 机体画面，因此实装前必须建立 `assets/eva/machines/` 并登记来源；在此之前，关键帧只能以几何占位显示 `MEDIA PENDING`，不得用 AI 机体图或伪造截图替代。
- 每台机体至少提供：全身/半身图、头部或胸部局部图、焦点坐标、允许裁切范围、来源和权利状态。

**字体尺度**

| 元素 | 1920 × 1080 | 390 × 844 |
|---|---:|---:|
| 机体大号编号 | 380–560px | 180–240px |
| 机体名 | 48–64px | 30–36px |
| 场景标题 | 72–96px | 38–44px |
| 状态/驾驶员 | 16–18px | 14px |
| 正文 | 17–20px | 15–16px |

**色彩**：机库近黑、冷白、应急橙；酸绿只用于扫描完成和同步状态。EVA-01 的眼与装甲局部可有紫/绿识别，但不允许全屏泛光。

**主交互**

- `00 / 01 / 02 / 08` 选择器改变机体纹理、编号、驾驶员、焦点与扫描部位；切换不可只换文本。
- 点击 `扫描缺陷` 或聚焦后按 `Enter`，扫描平面在 600–900ms 内通过机体，揭示故障标注；页面滚动仍可中断动作。
- 指针横向移动让镜头围绕机体摆动 ±8°，并轻微改变扫描环透视。

**移动端翻译**

- 机体影像放上方 52vh，编号缩到背景；选择器改为四项横向选项卡。
- 深度扫描改为三层遮片依次揭示，不启用镜头绕行和真实景深。
- 数值和正文统一进入下方 DOM 面板，禁止贴着机体图叠小字。

**Three.js / GSAP 钩子**

- 相机 `C(-2, 0.7, 9)` → `C(1.8, 0.5, -1)`，`T(0, 0.2, -8)`；`FOV 36→56`。
- 扫描面位置 `z=-7→1`，材质使用薄透明片与边缘亮线；只对扫描区域启用局部色偏，不对全屏加 RGB shift。
- 机体切换用 `gsap.timeline()` 控制舱灯、编号、纹理与 DOM 数据一致性；纹理加载完成前保留旧影像和 `LOADING` 状态。

### K04 / ANGELS：AT 力场接触与中和

**镜头功能**：把“心之壁”从抽象概念变成可触摸、可变形、可击碎的空间。反派阵营的视觉差异应在这里最集中。

**构图**

- 镜头置于一个半透明多面体内部，八边形棱线从四面汇聚到中心。画面中央偏右悬浮当前使徒，左下方是 DOM 使徒档案与 `中和 AT 力场` 按钮。
- 萨基尔、拉米尔、力天使、塔布里斯分布在力场不同棱面上；每次只放大一个主体，其他作为远处的低对比残影。
- SEELE 标志只作为低透明度来源标记或转场印章，不覆盖使徒主体，不把神秘组织变成背景壁纸。
- 力场闭合时画面几乎全红；中和后红色退到棱线，黑场与骨白档案成为主阅读区。

**前 / 中 / 远景**

- 近景：弯曲的棱线、红色粉尘、DOM 档案和交互按钮。

## 3. 连续 12 帧动态分镜

### 3.1 全局节奏

下表是 ScrollTrigger 的默认叙事分割。`p` 是全站进度，不是用户必须精确滚到的数值；实现时由每个 section 的起止位置换算出归一化值。

| 场景 | 全局 `p` | DOM 锚点 | 空间任务 | 节奏 |
|---|---:|---|---|---|
| 00 INITIALIZE | 0.00–0.10 | `#top` | 力场闭合、主动破门 | 静止 → 单次强动作 |
| 01 CHILDREN | 0.10–0.32 | `#children` | 双面角色与人物档案 | 横移 + 翻转 |
| 02 EVANGELION | 0.32–0.47 | `#evangelion` | 机库穿行与深度扫描 | 推进 + 横移 |
| 03 ANGELS | 0.47–0.66 | `#angels` | 力场接触、弯曲、碎裂 | 内含 → 向外爆裂 |
| 04 TOKYO-3 | 0.66–0.78 | `#tokyo-3` | Geofront 到地表 | 垂直上升 |
| 05 RECORDS | 0.78–0.90 | `#records` | 六代媒体胶片走廊 | 纵深穿行 + 年份跳切 |
| 06 RELEASE | 0.90–1.00 | `#release` | 力场聚合、崩解、白场 | 收束 → 彻底消失 |

推荐 `ScrollTrigger` 长度预算：`#top +160%`、`#children +360%`、`#evangelion +320%`、`#angels +360%`、`#tokyo-3 +320%`、`#records +280%`、`#release +240%`。这些长度不是页面高度本身，而是固定镜头段的滚动距离。

### F01 / 拒绝接入

- **区间**：`p=0.00–0.03`，`#top` 本地 `s=0.00–0.20`。
- **画面**：黑场、闭合的红色八边形、极细同步刻度。DOM 标题与两个入口按钮已经出现，透明度为 1；禁止“先黑屏等 WebGL”。
- **相机**：`C(0,0,8) → C(0,0,7.2)`，`T(0,0,0)`，`FOV 38`。只有非常慢的推近，不能持续漂移。
- **景深**：焦点在力场中心，DOM 永远保持清晰；后方影像层不可见。
- **遮片 / 硬切**：力场棱片全闭合；中心保留一道 2–4px 黑色裂缝，表达“系统尚未允许”。
- **AT 力场**：`closure=1`、`fracture=0`、`open=0`。
- **主交互**：按钮可聚焦；键盘焦点环为暖白 2px，不用酸绿大面积发光。
- **音频**：默认静音；点击“开始同步”后才可请求环境声，禁止自动播放语音。

### F02 / 力场破门

- **区间**：`p=0.03–0.10`；点击“开始同步/静音浏览”触发一次性的 1.4–1.8 秒动作，但滚动仍可继续。
- **画面**：八块棱片先向内压缩，再向外错开；中心裂缝扩展成一人宽的入口。标题被切成上下两半，真实影像从后方透出。
- **相机**：`C(0,0,7.2) → C(0,0,3.6)`，`FOV 38→54`，注视点轻微下压 `T(0,-0.15,0)`。镜头穿过力场平面，但不做第一人称剧烈摇晃。
- **景深**：焦点从力场中心平滑转到后方主视觉；高画质下近景棱线产生窄幅失焦。
- **遮片 / 硬切**：`p≈0.10` 在镜头穿出后硬切到 `#top` 主视觉，插入 1–2 帧近黑；不使用白色闪屏。
- **AT 力场**：`open=0→1`，每块棱片绕自身法线错位 8–18°，中心 alpha 从 0.92 降到 0.18。
- **主交互**：动作可由滚动中断；若用户未点按钮而直接滚动，力场保持薄透明但正文可读，不制造滚动陷阱。
- **移动端**：压缩为 180ms 八边形遮片 + 硬切，不执行完整穿屏。

### F03 / 主视觉建立

- **区间**：`p=0.10–0.16`，`#top` 本地后段。
- **画面**：真实群像或官方主视觉横向铺开，近景标题与远景人物形成两层空间。`享受 / 独处` 作为情绪副标题，`同步协议` 是主叙事标题，二者不可互相争抢。
- **相机**：`C(0,0,2) → C(0,0.15,-1)`，`T(0,0,-6)`，`FOV 48`；只做一次缓慢推移，不再无限悬浮。
- **景深**：群像脸部清晰，后方雨夜/城市纹理降对比；高画质可使用极窄景深，移动端关闭。
- **遮片 / 硬切**：群像从左右三个不等宽遮片内滑入，后面跟随一条偏轴红色扫描线；扫描线只经过一次。

- **排版**：主标题不跟镜头移动，固定在 DOM 安全区；人物图可以轻微视差，文字不旋转。
- **主交互**：阵营入口应改为章节入口或人物/机体/使徒索引，避免用户以为仍是两页静态名单。

### F04 / 适格者走廊展开

- **区间**：`p=0.16–0.24`，`#children` 本地 `s=0.00–0.40`。

- **遮片 / 硬切**：角色牌从纸白遮片内外露，每张只露一次；不使用 sibling stagger 把五张卡同时上浮。

- **加载策略**：优先加载当前机体与相邻机体纹理；其余机体使用低分辨率 poster。切换失败时保留旧机体并显示可读错误。

- **画面**：黑场里先出现 SEELE 的红线八边形，再向后展开为多面体。萨基尔从力场右侧接近，红色线框掠过其面具；DOM 侧边标题 `心之壁 / AT FIELD` 先出现。

- **遮片 / 硬切**：从机库硬切到红黑场；八边形以 160–220ms 几何展开，不作泛光爆炸。
- **AT 力场**：沿用 K01 拓扑，但尺度变为包住镜头的多面体；`closure=1`，可见棱片数增加，中心维持半透明。
- **叙事**：SEELE 在此时以 `SOUND ONLY` 短印章出现，表示“人类补完委员会正在观察”；它不打断使徒介绍。

### F09 / 中和力场

- **区间**：`p=0.56–0.66`，`#angels` 本地 `s=0.40–1.00`。
- **画面**：使徒档案从右侧滑入，力场棱线被拉到极限；用户点击 `中和 AT 力场` 后，棱片从使徒轮廓向外分离，档案转为可读的黑底骨白状态。画面不是逐渐淡出，而是“边界消失后突然清楚”。
- **相机**：`C(0,0,2.4) → C(0,-0.3,0.8)`，`T(0,0,0)`，`FOV 62→54`；碎裂时镜头只退半步，不剧烈震动。
- **景深**：中和前焦点在力场核心，中和后焦点切到 DOM 文档区与使徒眼睛；高画质下可在破碎瞬间短暂降低景深。
- **遮片 / 硬切**：碎裂由 8–16 块棱片驱动，每片沿各自法线向外并扭转；释放 1–2 帧黑场，再显档案。禁止全屏白闪。
- **AT 力场**：`fracture=0→1`，棱片透明度从 0.72 到 0；红色退为细线，骨白文字接管画面。
- **主交互**：按钮的 `aria-pressed` 或明确状态文字从 `力场展开` 变为 `已中和`；再次点击可重新聚合，必须有视觉反馈。
- **状态保持**：用户已中和的使徒在返回时保持已解锁；不能因滚动离屏重置交互状态。

### F10 / 第三新东京市上升

- **区间**：`p=0.66–0.78`，`#tokyo-3` 本地 `s=0.00–1.00`。
- **画面**：从 AT 力场碎裂的黑场硬切到地下 Geofront，镜头向上仰视；装甲板、井口、楼群和探照灯按不同时间升起，最后露出夜空与竖排城市标题。
- **相机**：`C(0,-8,10) → C(0,3,7)`，`T(0,1.5,-18)`，`FOV 46→34`；轨迹是连续上升，不使用 2D 背景滚动。
- **景深**：焦点从近景装甲板移到地表楼群；高画质下远景天空保持低对比，不抢结构边缘。
- **遮片 / 硬切**：起始黑场由井口轮廓打开；楼群不淡化，而是被上升几何遮蔽后逐渐露出。结束时镜头接近地表，硬切到胶片走廊。
- **城市行为**：至少 5 个升起阶段：地下梁架 → 平台 → 低层建筑 → 高层与道路 → 探照灯/月光。每阶段至少有两类几何改变，而不是同一组楼整体位移。
- **真实影像**：现有 `tokyo-alone.jpg`、`tokyo-rain.jpg`、`empty-train.jpg` 是现实空镜，只能作为氛围和视频记录，页面上标注 `ATMOSPHERE / NON-OFFICIAL`；不得作为第三新东京市官方剧照。
- **主交互**：滚动是唯一上升驱动；城市节点是可聚焦按钮，打开短档案时不改变滚动位置。雨夜视频离屏暂停。

### F11 / 两个时代胶片走廊

- **区间**：`p=0.78–0.90`，`#records` 本地 `s=0.00–1.00`。
- **画面**：六块纵向悬挂的海报/剧照在空间中形成一条走廊，依次代表 1995 TV、旧剧场版、1.0、2.0、3.0、3.0+1.0。每块影像有年份、载体和来源标记。
- **相机**：`C(0,0,10) → C(0,0,-14)`，`T(0,0,-20)`，`FOV 40`；镜头沿走廊前进，不做无意义的相机自转。
- **景深**：焦点在最近一块影片；后面的海报缩成几何色块，保持“年代在前方依次出现”的节奏。
- **遮片 / 硬切**：年份切换以胶片边框遮片和 2 帧黑场跳切为主；同一年代内部才允许 150–250ms 细节位移。点击年份后，镜头可以跳到对应画面前，但内容详情进入可读二维层。
- **真实影像**：六块材质必须是可核验官方海报/剧照或明确授权的替代档案；当前素材目录没有完整六代海报，必须补档。无素材年份显示空片框、年份与 `SOURCE PENDING`，不得拿同人图冒充。
- **DOM 可读性**：详情层位于固定左侧，显示标题、年份、媒介、初映信息、来源和外部官方入口；不是把长正文贴在海报上。
- **主交互**：年份按钮和走廊前后按钮都可操作；键盘 `←/→` 移动年代，`Enter` 展开详情；视频只作为 4–8 秒静音预览。

### F12 / 心之壁聚合与崩解

- **区间**：`p=0.90–1.00`，`#release` 本地 `s=0.00–1.00`，内含三个子阶段。
- **画面**：先出现 LCL 红海与最后一块真实影像，八边形 AT 力场从首屏状态重新聚合，像要把所有角色和年代封回黑场；用户点击 `解除 AT 力场` 后，棱片向内坍缩，影像逐层被吸走，最后只剩骨白终幕卡与来源索引。
- **相机**：`C(0,0,12) → C(0,0,3)`，`FOV 48→64`；聚合时缓推，崩解时沿 Z 轴穿入中心，随后切到纯黑，再以 DOM 白场出现。
- **景深**：聚合期焦点在八边形中心；崩解期所有影像变虚并被吸入，最终取消景深，让终幕文字绝对清晰。
- **遮片 / 硬切**：`0.90–0.93` 聚合；`0.93–0.96` 用户触发崩解；`0.96–0.98` 近黑硬切；`0.98–1.00` 白场与来源索引。禁止把崩解做成普通卡片淡出。
- **AT 力场**：复用首屏材质和棱片拓扑：`closure=1 → fracture=1 → opacity=0`。聚合是“同一结构回来”，不是新做一个特效。
- **终幕内容**：保留 `不必艳羡风月，孤岛有孤岛的好。`、日语短句、九角色索引、声音控制与完整来源。`#release` 必须先可读，再发生崩解；用户不应为了看来源而被强制交互。
- **主交互**：按钮可点击，`Enter/Space` 可用；未触发时滚动仍可完成页面，避免阻断。触发后状态保持，返回顶部可重新播放一次，但不自动循环。
- **声音关系**：若声音已开启，环境声可作为波形电平驱动八边形呼吸；未开启时不得假装有现场音频。日语语音仍然单独播放，标签保持 `合成音声 · 非原声`。

### 4.1 总关系

| 场次 | 空间层 | DOM 层 | 进入方式 | 退出方式 | 不能被淡入替代的行为 |
|---|---|---|---|---|---|
| 00 `#top` 接入 | 闭合力场、穿屏、主视觉 | 标题、两种进入方式、同步率 | 由用户主动开门 | 穿出后硬切 | 八边形棱片打开 |
| 01 `#children` 适格者 | 纵深角色廊、双面卡、指挥副层 | 驾驶员档案、年代切换、语音 | 纸白遮片露出 | 百叶合拢 | 角色卡翻面 |
| 02 `#evangelion` 机体 | 机库门、多层机体、三维扫描面 | 机型选择、驾驶员、缺陷数据 | 水平门缝打开 | 扫描线拉黑 | 镜头围绕机体横移与扫描 |

| 06 `#release` 终幕 | 红海、聚合力场、崩解、黑场 | 终幕文案、角色索引、环境声、来源 | 聚合回响 | 用户解除力场 | 聚合后彻底崩解 |

### 4.2 DOM 阅读模型

1. **阅读顺序不依赖 Canvas。** 每个 section 的 `h2`、首个可操作控件、正文和来源必须在文档流中按逻辑排列。Canvas 作为装饰层 `aria-hidden="true"`，不进入 Tab 顺序。
2. **固定阅读区承担正文。** 桌面 NERV 场景的主阅读区在左侧 34–40vw；SEELE 场景可换到右侧以表达阵营差异，但同一场景内部不能移动。移动端统一为下方 42vh 面板，不能把介绍贴到人物脸或机体边缘。
3. **一个时刻只强调一个读对象。** 角色、机体、使徒或年代的选中项以 `aria-current="true"` 或 `aria-pressed` 明确，其他项仍可通过导航访问。禁止所有隐藏文本继续被屏幕阅读器逐个朗读却不显示。
4. **正文不做空间文字。** 中文字体不进入 Three.js；WebGL 只保留超大日文/数字作为画面结构。所有可读段落仍使用真实的 HTML 文本、标准换行和选择能力。
5. **状态反馈语义化。** `开始同步 / 静音浏览`、`1995 / 2021`、`00/01/02/08`、`中和 AT 力场`、`播放/暂停` 都要有明确 `aria-label`、`aria-pressed` 或状态文本；不要只靠颜色和 glitch。
6. **焦点不被镜头偷走。** 场景切换只改变视觉层，不调用 `focus()` 到非用户目标；只有用户点击按钮或按键盘后才移动焦点。
7. **提供静止阅读模式。** 顶部或辅助菜单增加 `静止阅读 / REDUCE MOTION` 开关；开启后禁用 ScrollTrigger 固定镜头，把所有场景按文档顺序展开，仍保留所有正文和音频控制。
8. **无 WebGL 时内容仍完整。** `<noscript>` 与 WebGL 失败状态需展示核心内容与来源；不允许用“请使用支持 WebGL 的浏览器”替代全部档案。

### 4.3 现有 DOM 到新锚点的迁移

现有 `index.html` 的结构是 `#top → .roster--nerv → .record → .roster--seele → .seele-terminal → .closing`。重构时应保留内容与语义，按以下方式映射，不重复创建完整角色档案：

| 现有节点 | 新归属 | 处理原则 |
|---|---|---|
| `.hero#top` | `#top` | 保留标题、群像和同步率；入口改为开始同步/静音浏览 |
| `.roster--nerv#nerv` | `#children` | 主角色 + NERV COMMAND 副档案；旧 `#nerv` 可作为兼容锚点，不复制 ID |
| `.record#record` | `#tokyo-3` 内的雨夜记录 | 保留 video、播放/暂停、seek；标注氛围空镜，不标官方剧照 |
| `.roster--seele#seele` | `#angels` | 使徒和 SEELE 档案；源堂从指挥副档案回链，不重复人物卡 |
| `.seele-terminal#ambient` | `#release` 的声音控制台 | 保留环境声、波形、时长；不自动播放 |
| `.closing` | `#release` | 保留终幕文案、角色索引、声音状态和来源摘要 |
| `.footer` 来源 | `#release` 后段或全局页脚 | 始终可读；不因终幕黑场或坍塌动画消失 |

新导航固定为 `#top`、`#children`、`#evangelion`、`#angels`、`#tokyo-3`、`#records`、`#release`。如果旧链接仍在外部传播，用不可见兼容锚点承接 `#nerv`、`#seele`、`#record`、`#ambient`，但不影响新的 DOM 顺序。

### 4.4 七场的逐场节奏

#### 00 / INITIALIZE 接入

- **空间行为**：AT 力场闭合 → 主动打开 → 镜头穿出。
- **DOM 主任务**：让用户知道可以开始、可以静音浏览；显示当前同步率和选择。
- **读法**：标题和两个按钮在首帧就可见；不需要先看完力场动画。即使 WebGL 加载慢，DOM 文案也可先读。
- **禁止**：全屏 only-loading、自动播放声音、用滚动锁定强制看完一段视频。

#### 01 / CHILDREN 适格者

- **空间行为**：角色牌沿纵深排列，卡片在 90° 侧面替换纹理，镜头只横移与轻抬。
- **DOM 主任务**：按角色读介绍、初登场、身份、独处记录、日语台词和语音按钮。
- **读法**：左侧档案始终在同一位置；切换角色只替换字段，不换阅读节奏。五个驾驶员与三个指挥副档案分组清晰。
- **禁止**：五张卡同时向上浮起、同一节重复 fade-up、每个人都使用相同大卡片模板。

#### 02 / EVANGELION 机体

- **空间行为**：穿过舱门，沿机体侧面移动，薄扫描面从机库深处推向前景。
- **DOM 主任务**：切换机型，读出编号、驾驶员、状态、缺陷和素材来源。
- **读法**：主体正文固定在左侧底部或左下；编号是空间层，不承担唯一识别。
- **禁止**：把机体截图放大当全屏背景、用一张扫描线遮罩冒充 3D 扫描。

#### 03 / ANGELS 使徒

- **空间行为**：从场外进入多面体，局部棱线随指针弯曲，点击后向外碎裂。
- **DOM 主任务**：使徒身份、首次接触、力场状态、中和动作、SEELE 关系和素材来源。
- **读法**：NERV 纸张质感退去，档案改为黑底骨白；中和前后同一阅读区只改变边框和状态，不移动正文位置。
- **禁止**：全屏 glitch、每句文本随机抖动、把 SEELE 标志铺满背景。

#### 04 / TOKYO-3 第三新东京市

- **空间行为**：相机从 Geofront 垂直上升，楼群分层从地下升起，天空和月光逐渐出现。
- **DOM 主任务**：城市身份、NERV 总部/避难层短档案、雨夜视频控制。
- **读法**：标题与视频控制放在稳定底部/左侧，视频不自动播放；播放状态和来源可读。
- **禁止**：整张城市图上下位移、滚动劫持、视频离开视口仍在后台播放。

#### 05 / RECORDS 两个时代

- **空间行为**：镜头沿六块悬挂海报穿行；点击年份跳到对应画面并打开二维档案。
- **DOM 主任务**：电视剧、旧剧场版、新剧场版四部曲的年份、标题、媒介、来源和官方入口。
- **读法**：详情层是普通 HTML，信息顺序固定：标题 → 年代 → 媒介 → 来源 → 外部入口。没有来源的影片显示 `SOURCE PENDING`。
- **禁止**：把无法核验的海报图当作官方资源，把外部官方链接伪装成站内视频。

#### 06 / RELEASE 心之壁

- **空间行为**：首屏八边形重新聚合 → 用户解除 → 整场向内坍缩 → 黑场 → 白场。
- **DOM 主任务**：终幕文案、九角色索引、环境声、合成音声明、素材来源与“返回 00”。
- **读法**：终幕先保证正文、按钮和来源可读，再提供崩解动作。用户不触发也能完成阅读。
- **禁止**：用白闪替代崩解、把来源藏进黑场、让音频自动循环且无停止方式。

## 5. 性能分级与降级路径

### 5.1 质量档位

| 档位 | 启用条件 | DPR 上限 | 力场棱片 | 城市实例 | 粒子 | 后处理 | 媒体 |
|---|---|---:|---:|---:|---:|---|---|
| HIGH | 桌面、WebGL2、内存充足、无省流 | 1.5 | 16–24 | 180–240 | 700–1000 | 窄半径景深 + 轻颗粒 | 分层真实影像、静音短片 |
| MEDIUM | 中端桌面/平板、内存一般 | 1.25 | 12 | 100–140 | 300–500 | 无景深，仅颜色/颗粒 | 2–3 层影像 |
| LOW | 移动、`saveData`、低内存、帧率不足 | 1.0 | 8 | 48–72 | 0–120 | 关闭 | 单层影像或 poster |
| STATIC | 无 WebGL、减少动态、用户选择静止阅读 | — | CSS/矢量静态 | — | — | 关闭 | 全部 poster + DOM |

### 5.2 渲染与加载硬约束

- 只保留一个 `WebGLRenderer`、一个主渲染循环和一个 `EffectComposer`；任意时刻只激活当前 section 的场景模块。
- 场景离屏后调用 `deactivate()`，停止该 scene 的相机更新、粒子、视频与音频；超过 2 个完整段落再离屏时，释放未共享纹理和 geometry。
- 首屏真实媒体预算 ≤3MB（压缩后），全部媒体预算 ≤25MB。DOM 与按钮应独立于 WebGL 启动，目标 2.5 秒内可操作。
- 当前 `group.png` 约 0.9MB、字体约 0.2MB、雨窗视频约 6.5MB；新增官方素材前必须给总量做清单，不能用同一段视频覆盖整个页面掩盖预算。
- 真实影像纹理长边优先 2048px；小角色牌使用 1024px；城市远景 poster 使用 1280–1600px。WebP/AVIF 优先，视频提供静音 MP4/H.264 回退以覆盖 WebM 兼容缺口。
- 每个激活场景的 draw call 目标 <80，三角形目标 <300k；城市优先 instanced mesh，AT 力场优先单个 shader 或 merged geometry。
- `setProgress()` 每帧最多调用一次；指针事件只更新目标值，实际阻尼在 RAF 中合并。禁止每个 pointermove 直接创建 GSAP tween。

### 5.3 自动降级

1. 排除页面隐藏和滚动暂停的时间；连续 2 秒低于 45fps，下降一个质量档位。
2. 降级顺序：关闭景深与颗粒 → 减少力场棱片和粒子 → 将城市几何换成静态层 → 切到 STATIC。
3. 检测到 `prefers-reduced-motion: reduce`、`navigator.connection.saveData` 或低内存时，首帧直接选择 LOW/STATIC，不先播放再降级。
4. WebGL context lost 时显示可读错误和 STATIC 版内容，最多尝试恢复一次；不得清空 DOM 或显示无限 loading。
5. 视频离屏或页面 `visibilitychange=hidden` 时暂停；音频在同一时间只允许一个主播放源，语音播放时环境声降到 0 或暂停。

### 5.4 `prefers-reduced-motion` 替代方案

使用 `gsap.matchMedia()` 建立独立分支，系统偏好与站内开关任一成立即进入 STATIC：

| 原动效 | STATIC 替代 | 必须保留的意义 |
|---|---|---|
| 首屏力场穿屏 | 静态闭合/开放两态图，按钮触发 160ms 遮片切换 | 用户完成“允许同步”操作 |
| 角色 3D 翻面 | 正面与背面立即切换，120ms 纸片遮片 | 知道 1995/2021 是两套记录 |
| 机体 3D 扫描 | 机体静态图上叠加固定扫描切面与缺陷标点 | 知道扫描部位和状态 |
| 使徒棱线弯曲/碎裂 | 静态“展开/中和”结构图，按钮改变文字与红色边框 | 知道力场当前状态 |
| 城市上升 | 三层纵向剖面静态展开，替代垂直镜头 | 知道 Geofront 到地表的结构关系 |
| 胶片走廊穿行 | 六个年代按纵向列表/横向分页显示 | 可逐代阅读与跳转 |
| 终幕坍缩 | 黑场快速过渡到白场卡片 | 知道叙事结束，仍可回看来源 |

STATIC 模式仍需保留 100–180ms 的按钮状态反馈、焦点环和音频进度；减少运动不等于禁用反馈。视频不自动播放，用户点击才可播放。

## 7. Three.js + GSAP 实现契约

### 7.1 运动论点

- **焦点动作**：AT 力场在首屏“拒绝接入”，在中和时碎裂，在终幕重新聚合后彻底崩解。这是唯一允许反复使用同一视觉对象的导演动作。
- **连续性**：场景之间用硬切与遮片保持电影性；同一 ATFieldMaterial 贯穿首尾。角色翻面和年代切换是唯一强调共享元素的局部连续性。
- **反馈**：所有按钮使用 100–180ms 的光圈收缩、扫描门切换或状态色变化；不以弹跳、卡片浮起和大面积发光回应点击。
- **预算**：真实影像分层、力场、城市与终幕是昂贵对象；每帧只让当前 section 更新。支持动效只负责方向和状态，不争抢焦点。

### 7.2 场景模块接口

所有 3D 场景使用同一接口，避免相机、滚动和音频逻辑散落在页面各处。具体实现可以放进一个 `SceneHost`，DOM 与内容仍由正常 HTML 驱动。

```ts
export interface EvaScene {
  // 加载纹理、创建几何和材质；返回可交互时机
  mount(renderer: WebGLRenderer, host: HTMLElement, assets: SceneAssets): Promise<void>;
  // p 为全站进度，s 为当前场景本地进度，二者均为 0..1
  setProgress(p: number, s: number): void;
  // 指针已归一化到 -1..1；禁止直接在每个 pointermove 新建 tween
  setPointer(x: number, y: number): void;
  // 来自已获用户授权的环境声/语音分析，范围 0..1
  setAudioLevel(level: number): void;
  activate(): void;
  deactivate(): void;
  dispose(): void;
}
```

`activate()` 只打开当前模块的渲染、相机和事件；`deactivate()` 必须停止视频、音频、粒子、requestAnimationFrame 调度和指针监听。`dispose()` 释放只属于该场景的纹理和几何；共享 ATFieldMaterial 只在应用卸载时释放。

### 7.3 内容数据结构

以下字段是新旧内容迁移的最小集合。所有字段保持英文标识符，正文、介绍、标签和来源说明使用中文；日文姓名、日文台词和官方英文标签保留原文。

```ts
type Faction = "nerv" | "seele" | "angel";
type Era = "1995" | "1997" | "2007" | "2009" | "2012" | "2021";
type QualityTier = "high" | "medium" | "low" | "static";

interface CharacterRecord {

  commandLink?: string;       // 源堂等跨档案关系
}

interface MachineRecord {

  number: "00" | "01" | "02" | "08";
  name: string;
  pilotId: string;

  depthLayers: { assetId: string; z: number; scale: number }[];
  cameraPath: string;

}

interface AngelRecord {
  id: string;
```

### 7.4 ScrollTrigger 与 GSAP 更新规则

1. 每个 section 只创建一个主 `ScrollTrigger`，`scrub: 0.6–0.9`；在 `onUpdate` 中计算本地 `s` 并调用当前 `EvaScene.setProgress(p, s)`。不要把每个 DOM 段落都绑定一套独立 parallax。
2. 点击型动作使用可中断的 `gsap.timeline({ overwrite: "auto" })`，例如开门、翻面和中和。滚动开始时停止当前未完成的点击动作，不让两个相机指令互相争夺。
3. 相机路径使用 `gsap.quickTo`/阻尼或在一个 RAF 中 lerp 位置与注视点；不要为每个 `pointermove` 创建 tween。
4. DOM 文本只在切换角色或年代时做一次 120–220ms 遮片；正文本身不做持续漂移。`will-change` 只在动作期间添加，完成后移除。
5. 大段空间切换调用中央 `cutToScene(nextSceneId)`：先显示 1–2 帧近黑遮片，再 `deactivate()` 当前场景并 `activate()` 下一场景，最后移除遮片。
6. 音量和波形更新使用平滑值，视觉上保持 0–1 范围；未获得声音权限时 `setAudioLevel(0)`，不让无输入波形伪装成正在播放。

### 7.5 AT 力场材质建议

共享 uniform 至少有：

```text
uOpen       0..1     // 首屏开门
uBend       0..1     // 指针局部弯曲
uFracture   0..1     // 中和崩解
uAudio      0..1     // 已授权声音的呼吸电平
uPointer    vec2     // 最近一次归一化指针
uQuality    float    // 细分与线条数量
```

- 八棱片由 8 个独立面片组成，面片共享材质但在场景侧保存自己的随机种子；碎裂方向由种子决定，刷新后仍可复现。
- 首屏：`uOpen=0`、`uFracture=0`、`uBend<=0.08`。
- 使徒场：`uOpen=1`、`uBend` 受指针局部控制、`uFracture=0`。
- 中和：`uFracture` 从 0→1，棱片法线方向和透明度同步变化。
- 终幕：重置 `uFracture=0`、`uOpen=0`，再触发更大幅度的崩解；不能重建一套视觉上不同的“第二力场”。

### 7.6 素材加载与场景切换

- 首屏只预加载字体、首屏标题所需 CSS、当前群像 poster 与极少量共享 shader 代码。
- `#children` 进入前 1 个视口时加载当前角色及相邻角色；`#evangelion` 进入前 1 个视口时加载当前机体与相邻机体；六代海报只在 `#records` 接近时加载。
- 纹理加载使用 `TextureLoader` 或 `KTX2Loader` 时显示确定性占位：编号、角色名、`MEDIA PENDING` 和来源状态，不用骨架屏抖动。
- 纹理失败时保留旧纹理与可读错误；不可让整个 WebGL 场景失效。
- 视频文件优先 `poster`；进入视口只加载 metadata，用户点击才播放。WebM 之外提供 MP4/H.264 回退，避免 iOS Safari 只剩静态图。
